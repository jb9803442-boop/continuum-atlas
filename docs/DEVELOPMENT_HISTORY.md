# Continuum — interactive human biology atlas

Run with Node.js 20 or newer:

```sh
GEMINI_API_KEY=your_new_key npm start
```

Open port 3000. Without an API key the atlas works; chat clearly reports that AI is unavailable and offers retry without presenting saved text as an AI answer.

## Content and interface
- `public/data.js`: replaceable system descriptions, concepts, and longevity context.
- `public/app.v13.js`: current navigation, side-panel concept selection, locally saved exploration progress, and contextual chat.
- `public/topic-visuals.js`: independent mapping of the 32 Human Biology concepts to their illustration, accessible description, and explanatory caption. Replace a `src` here to use supplied images.
- `public/illustrations/`: 141 distinct topic/step illustrations, 4 Aging branch illustrations, 2 Disease & Death branch illustrations, 1 identity overview, 1 Ethics overview, 1 Future Scenario overview, and 9 Futurist branch overviews, served locally as SVGs. Abstract concepts are explicitly labeled conceptual; anatomical images are simplified, not to scale.
- `create_illustrations.py`: reproducible illustration asset generator.
- `tests/illustrations.mjs`: browser tests for all topic images, side-panel-only rendering, return navigation, and mobile overflow (requires Playwright).
- `public/style.css`: responsive dark atlas interface, reduced-motion support.
- `server.mjs`: static server and server-side Gemini chat proxy. The credential never goes to the browser and is not stored in source files.

The Scientist and The Philosopher are implemented pathways. A third pathway is explicitly marked unavailable pending content. The generated central avatar is an illustrative visualization, not an anatomically validated medical diagram. Biology summaries are introductory editorial content, not live research retrieval. Gemini chat does not include web grounding.

Live chat was successfully tested with the replacement credential and gemini-3.8-flash. The previous failure was a model-availability error: the service reported that gemini-2.5-flash was no longer available to new users. Credentials are provided only through the server environment; set GEMINI_API_KEY again when restarting. Rotate any key that has been pasted into a conversation.

For public production deployment, add authentication, request rate limits, spending limits, and a reverse proxy with HTTPS before exposing the AI endpoint.

## Personalized Reflection Lab
After the seventh replacement, choose **Analyze my reflections**, or use **View my reflection analysis** at any point.

- `public/identity-reasoning.js`: transparent local reasoning engine. It distinguishes blank answers from explicit uncertainty, identifies accepted/rejected steps, tentative boundaries, and later returns to acceptance without automatically calling them contradictions. Interpretations quote the actual sequence and name their limits.
- `public/identity-analysis-ui.js`: evidence panel, personalized initial report, four adaptive follow-ups, optional written reasons, revised working interpretation, source links, and explicit opt-in transfer to Atlas.
- The questions distinguish the meaning of “same person,” a proposed continuity condition, a targeted counterexample, and a branching or ethical test. There are eight probe variants across the latter two question stages. Follow-up answers refine the reasoning instead of assigning a fixed philosophy or personality type.
- Notes are stored verbatim and are not semantically analyzed by local rules. Sending them to the AI service requires the separate **Send this reflection to Atlas** action. Normal local analysis makes no AI requests and continues to work when Gemini is unavailable.
- `continuum-identity-inquiry` stores the current choice sequence and optional notes in browser local storage. A signature binds them to the seven initial reflections. Changing a base reflection starts a new inquiry; changing an earlier follow-up clears dependent later answers. Skipped questions remain explicitly unresolved.
- Philosophical grounding: Stanford Encyclopedia of Philosophy, *Personal Identity* (Spring 2013 archive, especially psychological continuity and fission), and *Personal Identity and Ethics* (Winter 2023 archive). These sources support the distinctions and debates, not empirical validation of a user-assessment method. Links and archive dates are shown in-app.
- `tests/identity-reasoning.mjs`: checks all 16,384 combinations of seven answers with missing values, plus 320 follow-up paths and eight adaptive probe variants.
- `tests/reflection-analysis.mjs`: browser checks for adaptive report content, different question routes, persistence, escaped notes, upstream and base-answer invalidation, opt-in AI evidence transport (mocked), empty states, and mobile overflow.

No philosophical profile is presented as a diagnosis, correct answer, validated psychological assessment, or proof of consciousness transfer. The analysis is intentionally provisional and distinguishes observed choices from interpretive possibilities.

## Full-body inspection and camera controls
- `public/avatar-viewer.js` fits the complete original 2D anatomical illustration inside its own viewport. It provides 50–300% zoom, bounded panning, mouse wheel zoom, keyboard controls, and two-pointer touch pinch in inspection mode.

Only the explicit **Inspect body** button hides labels. **Show topics** restores labels without changing the zoom or pan position. **Fit body** centers the entire illustration without changing the selected topic; the top reset button restores the default map view.
- `public/anatomy-clear.png` is a full-resolution transparent-background derivative of the original illustration. The head and feet are not cropped, and the former radial fade mask is removed. This is a 2D illustration viewer, not a rotatable 3D mesh.
- Tablet/desktop minimum-height conflicts are corrected so the camera controls remain within the workspace. On mobile, page scrolling remains available in map mode; use a zoom control or choose Inspect body to enable single-finger pan and two-finger pinch. Zooming enables gestures without hiding topics.
- Keyboard in the focused body region: +/− zoom, arrow keys pan, 0 fits, Escape returns to topics. Double-click also fits.
- `tests/avatar-viewer.mjs` verifies whole-image fit, toolbar bounds at five responsive sizes, zoom limits, panning, mouse wheel, keyboard, real CDP touch pinch, preserved topic selection, and restored map visibility.
